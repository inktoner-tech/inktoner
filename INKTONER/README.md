## Publicar en GitHub Pages
1. Descomprime el archivo ZIP.
2. Sube el contenido de la carpeta `INKTONER` al repositorio configurado para el sitio.
3. En GitHub: Settings → Pages → selecciona la rama y `/ (root)`.
4. Comprueba `https://abdielabrek69.github.io/INKTONER/` y envía el sitemap desde Google Search Console.

## SEO: importante
No existe un cambio que garantice aparecer primero en Google. Los resultados dependen de competencia, contenido útil, indexación, autoridad, rendimiento y señales locales. Confirma que el dominio canonical y los enlaces coincidan con el dominio publicado; solicita indexación en Search Console después de desplegar.
